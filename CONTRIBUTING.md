1. Для табцуляции используем табы
2. Объекты должны иметь чёткие и понятные названия отражающие суть
3. Один класс - одно действие (не дословно)
4. Комментарии только в отдельной строке - исключения названия классов
5. Названия функций пишутся через CamelCase
6. По возможности создаём static методы для упрощения кода и уменьшения создаваемых объектов
